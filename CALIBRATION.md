# Calibration

Diagnostic and gate scores. Add a **new column** (date in `YYYY-MM-DD`)
at each calibration so drift is visible. Do not overwrite old cells.

**Scale (1–5)**

| n | Meaning |
|---|---|
| 1 | Cannot do this unaided; folklore only |
| 2 | Can do it; cannot explain why it works |
| 3 | Can explain and debug typical cases |
| 4 | Can teach it; catches naive-but-wrong answers |
| 5 | Can operate at the ugly edges (source, production, design trade-offs) |

Update at: bootstrap diagnostic (`docs/06-BOOTSTRAP.md` step 4), every
phase gate, and when maintenance shows a clear drop. Do not invent
scores.
